# مطابقة الفيزا — تطبيق الموبايل

تطبيق Flutter (Android + iOS) يتصل ببرنامج **مطابقة الفيزا** على الشبكة المحلية، مع دعم كامل للعمل أوفلاين بعد المزامنة.

## الجديد في 1.2.0+3
- محتاج برنامج الكمبيوتر **2.6.0** أو أحدث.
- **أوفلاين بنفس شكل السيستم بالظبط**: التطبيق بيحفظ نسخة كاملة (الشاشات + كل بيانات الفيزا والكاش). لو الكمبيوتر مش متاح، تبويب السيستم بيفتح منها لوحده، من غير أي شريط على الشاشة. التعديل من الكمبيوتر بس.
- **تبويب "المزامنة والنسخ"**: مزامنة كاملة تلقائية أو بزرار، ونسخ احتياطية (يومي / كل مزامنة / مقفول، وعددها)، وكل نسخة تقدر تعرضها أو تبعتها أو تمسحها. نسخة الموبايل تترجع على الكمبيوتر من الإعدادات ← استرجاع نسخة.
- **قفل التطبيق برقم سري أو بصمة** (الحساب ← قفل التطبيق).
- الاسم بقى "رقابة الفيزا والكاش". `MainActivity` بقت `FlutterFragmentActivity` والمانيفست فيه `USE_BIOMETRIC` (لازمين للبصمة).
- امسح النسخة القديمة من الموبايل قبل ما تسطب الجديدة.

## الجديد في 1.1.0+2
- **تبويب "السيستم"** (أول تبويب): بيفتح نفس شاشات برنامج الكمبيوتر جوه التطبيق، بنفس الحساب ومن غير ما تسجل دخول تاني. فيه كل حاجة: فيزا وكاش والإجمالي، والتقارير، والتقييم، واستلام الكاش، والبحث، وتقرير الكاشير.
- **الصور وExcel وPDF**: أي زرار "صورة" أو "Excel" أو "PDF" أو "أرشيف كامل" بيجهز الملف ويفتح المشاركة، وتختار منها واتساب أو Drive أو غيرهم.
- **التبويبات القديمة** بقت اسمها "ملخص سريع" و"أوفلاين"، وبتشتغل من غير نت من آخر بيانات اتحفظت.
- لازم برنامج الكمبيوتر يكون 2.5.0 أو أحدث، عشان التبويب الجديد يشتغل.
- مكتبات جديدة: webview_flutter 4.9.0، وwebview_flutter_android 3.x، وshare_plus ^7.2.2. ملفات أندرويد زي ما هي.

## المميزات

- **اكتشاف تلقائي** للسيرفر على نفس الواي فاي (بدون كتابة الـ IP)
- تسجيل دخول بنفس حسابات البرنامج
- مزامنة **تلقائية** عند الاتصال بالشبكة المحلية
- تخزين محلي للتقارير (تقدر تشوفها وأنت برة الشبكة)
- لوحة تحكم + تقارير الفروع والكاشيرات والزيادة والعجز والفجوات
- **شاشة تفاصيل الكاشير**
- واجهة عربية كاملة (RTL) بتصميم محسّن

## الربط مع برنامج الكمبيوتر

- البرنامج من نسخة **1.9.3** وطالع بيتعرف على التطبيق لوحده (بالهيدر `X-Client: visa-recon-app`) وبيرجعله البيانات بالشكل اللي الشاشات بتقراه:
  - لوحة التحكم: `kpi.sys / bank / diff / problems / branches / cashiers / nSys / nBank` و`series` للرسم اليومي.
  - الفروع والكاشيرات: `diff` موجب = عجز، سالب = زيادة (بعد المؤثرات والموازنة الذكية). الكاشيرات من غير صفوف الإجمالي.
  - الزيادة والعجز: لكل فرع `over` (زيادة) و `under` (عجز).
  - الفجوات: `amt` المبلغ و `cashier` الكاشير أو الكارت.
  - تفاصيل الكاشير: `summary` (سيستم/بنك/الفرق) و `rows` العمليات اللي فيها فرق بس.
- نفس الحسابات والصلاحيات: مدير الفرع بيشوف فرعه بس.

## المتطلبات

1. برنامج مطابقة الفيزا شغال على الكمبيوتر
2. من البرنامج: **الإعدادات → الوصول من الموبايل** → شغّل السيرفر
3. الموبايل على **نفس الواي فاي**

## التشغيل للتطوير

```bash
cd visa_recon_mobile
flutter pub get
flutter run
```

## البناء

```bash
# Android APK
flutter build apk --release

# Android App Bundle
flutter build appbundle --release

# iOS (على Mac)
flutter build ios --release
```

## أول استخدام

1. افتح التطبيق
2. دوس **بحث** — التطبيق هيدوّر على السيرفر تلقائي على الشبكة
3. اختار السيرفر اللي يظهر
4. سجّل دخول بنفس اسم المستخدم والباسورد
5. البيانات هتتزامَن تلقائي

> لو البحث ما لقاش حاجة، تقدر تدخل العنوان يدوي (مثال: `http://192.168.1.15:8642`)

## هيكل المشروع

```
lib/
  core/
    api/           # عميل الـ API
    db/            # قاعدة البيانات المحلية (أوفلاين)
    models/
    services/      # Auth + Sync + Discovery
    theme/
  features/
    auth/          # تسجيل الدخول + اكتشاف السيرفر
    dashboard/
    reports/       # التقارير + تفاصيل الكاشير
    settings/
    home/
  widgets/
```

## البناء على GitHub Actions

1. ارفع المشروع على GitHub (مستودع جديد)
2. من تبويب **Actions** شغّل workflow اسمه **Build APK** (أو ادفع أي تعديل على `main`)
3. بعد ما يخلص البناء، من صفحة الـ run دوس **Artifacts** وحمل:
   - `visa-recon-debug-apk`
   - `visa-recon-release-apk`

تقدر تشغّله يدوي: Actions → Build APK → Run workflow
